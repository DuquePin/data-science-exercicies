# Credit Scoring Final Project
This final project is part of the **Data Scientist Profession** course at **EBAC**. 
The objective is  to develop a **machine learning classification model** to
identify **clients with default** in a credit institution's database.
## Project Overview
The project consists of two main components:
- 1 - **Jupyter Notebook**
  - A step-by-step demonstration of building a **classification model** for credit risk assessment.
  - Includes **data preprocessing, feature selection, model training by different approaches, evaluation,** and **performance analysis**.
- 2 - **Streamlit Web Application**
  - Allows users to upload a dataset and select a fraction for **sampling**.
  - Enables the selection of **independent variables (features)** and the **dependent variable (target)**.
  - Supports loading a **pre-trained model** to evaluate its performance on the sampled dataset.
  - Provides an intuitive interface for analyzing **model predictions** and **performance metrics.**
 
This project bridges the gap between **machine learning development** and **user-friendly deployment**, enabling users to assess 
credit risk efficiently.
